Tap to TradeTap to Trade

Full-stack / Capstone +

Connecting local players,
one trade at a time.

A marketplace for Magic: The Gathering players to share bulk inventories, search by card and city, and arrange in-person trades. My final-year capstone brings inventory management, offers and moderation into one web application.

Searchable inventories and counter-offers help players find a match. Role-based moderation and report handling keep the community manageable.

The personal column

The personal column / The personal column / 

I’m a software developer based in Hamilton, Ontario, with a background in software development at Mohawk College. I work across full-stack web applications, games and visual media.

I enjoy the details: tracing a bug, shaping an interaction, or connecting a front end to the data behind it. I write clean, testable code and see projects through to deployment.

Outside the code, I make videos, edit photos and produce short films. That interest in visual storytelling carries into the software and games I build.
